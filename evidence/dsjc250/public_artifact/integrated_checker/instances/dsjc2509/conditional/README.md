# DSJC250.9 conditional-envelope campaign data

This directory contains the integrated campaign descriptors, complete canonical column tables, rational certificates, six tree wrappers and payloads, and primal witnesses. The checker reconstructs every stable-set family from the external hash-identified graph and requires exact semantic/order/hash equality with the supplied model data. Optimizer statuses and floating-point generation data are not proof inputs.

The graph is fetched separately and authenticated by its recorded hashes. Run the campaign from the artifact root with:

```sh
./scripts/replay_integrated.sh /external/DSJC250.9.col [output.json]
```

The six actual tree payloads close entirely with integer-dual leaves. Matching/Tutte--Berge terminals are supported by the checker but unused in this campaign.
