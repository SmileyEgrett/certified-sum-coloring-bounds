# Generating the certificates

The generation commands in this directory implement the conditioned method in
the paper. They start with a benchmark graph, enumerate its stable sets, build
the packing or conditional optimization problems, and write the certificates
used by the exact checkers. The objects in `reference/` are a complete fresh
reproduction of these lower-bound computations.

## DSJC250.9

Enumeration finds three stable sets of size five, 205 of size four, and no
size-six stable set. The profile enumeration considers every class-size vector
with sum at most 8,276 and with at most two size-five classes. The generators
construct five rational covering duals and six packing branch trees for the
remaining conditional obligations.

The tree generator is
`source/existing/dsjc250/generate_lpbb.py`. At each node it constructs the
remaining packing LP and solves it through SciPy's HiGHS interface. It converts
the LP dual into integer numerators over a fixed denominator and repairs any
deficient column inequalities. A node closes only when the resulting exact
dual bound is strictly below the target after accounting for selected columns.

If this bound does not close the node, the program selects a fractional LP
column. It prioritizes the larger score, then closeness to one half, then the
larger LP value, with a deterministic index tie-break. One child excludes that
column; the other selects it, decreases its remaining size quota, and removes
intersecting columns. Both children must close. The output records this tree
and the integer dual at each leaf. The checker reconstructs the full column
family and verifies every branch and leaf before using the conclusion in the
profile argument.

Thus the branching is performed by the supplied program. HiGHS is used for
the node LPs. This generation route is separate from the complete integer-master
HiGHS computations supplied elsewhere in the companion.

## DSJC500.9

There are 23 size-five stable sets and eight maximum packings, each containing
15 such sets. For each packing the generator removes its 75 vertices and
constructs a rational cover of the remaining size-four stable sets. Where
required, a packing branch tree improves the integer consequence of that cover.
Additional exact Farkas certificates exclude particular class-count profiles.

The weighted conditional models are generated by
`source/existing/dsjc500/delta/make_conditional_model.py`, and their trees by
`exact_mscp_conditional_discover.py` in the same directory. Their scores and
quotas are explicitly specified in `source/config/STAGES.json`; the complete
column lists, model descriptors and proofs are saved in each run. The exact
verifier reconstructs each model and checks which profiles its conclusion
excludes.

At threshold 29,790 the arithmetic enumeration gives 46 profiles. All require
a maximum size-five packing, so the proof checks 46 times eight, or 368,
packing/profile combinations. Each must have an applicable, verified exclusion.
This establishes the lower bound 29,791. The software does not treat the three
remaining cells at that value as the complete task of proving 29,848 optimal.

## DSJC1000.9

The graph has three mutually disjoint size-six stable sets and no size-seven
stable set. Their inclusion or exclusion gives eight conditional cases. The
generator builds a complete conditional LP for each case using the eligible
stable sets. In the case that selects all three size-six sets, a separate
packing calculation supplies a rational certificate proving that at most 134
size-five sets can be packed in the residual graph. This cap is verified before
the capped conditional LP is allowed to run.

The numerical solutions and dual arrays are retained. The exact reconstruction
code in `source/new/construct.py` rounds and repairs the dual coefficients in
the required directions and checks every eligible stable-set inequality. The
independent verifier checks the rational certificate and the scenario's scope.
Every one of the eight resulting bounds is strictly above 102,343, establishing
the integer lower bound 102,344. No assertion of exact LP optimality is needed.

## C2000.9

The stable-set census finds 90 size-six sets and no size-seven set. A separate
C++ enumeration checks this family directly from the graph. Two positive
combinatorial objects establish the exact size-six packing maximum of 52:

- a list of 52 pairwise-disjoint size-six stable sets;
- a partition of all 90 size-six sets into 52 groups, each consisting of
  pairwise-intersecting sets.

The generator constructs the conflict graph of the size-six sets, enumerates
its maximal cliques, and uses integer programs to find the packing and clique
cover. The cover is converted to a partition. The checker verifies disjointness
of the packing, pairwise intersection within each group, and complete coverage
of the 90 sets. These properties certify both sides of the packing maximum
without using an integer solver's optimality status as a proof premise.

The arithmetic profile bound then minimizes the sum with at most 52 size-six
classes and maximum class size six. The exact checker obtains 381,823.

## Source and output map

| Component | Location |
|---|---|
| Stage arguments, dependencies and output names | `source/config/STAGES.json` |
| Enumeration, rational reconstruction and C2000.9 constructions | `source/new/construct.py` |
| Numerical solver adapter and thread readback | `source/new/numerical.py` |
| DSJC250.9 tree generator | `source/existing/dsjc250/generate_lpbb.py` |
| DSJC500.9 generators | `source/existing/dsjc500/` |
| DSJC1000.9 LP generators | `source/existing/dsjc1000/` |
| C2000.9 stable-set enumeration | `source/existing/c2000/` |
| Exact checkers | `source/checkers/` and conditional verifiers in `source/existing/dsjc500/delta/` |
| Graph-to-bound composition | `source/new/verify_lower.py` |
| Fresh objects and run transcripts | `reference/stages/` |
| Complete per-stage accounting | `reference/stage-timings.json` |

The validation role of each component is distinct: numerical solvers propose
coefficients or combinatorial objects; exact checks establish their validity;
the profile and case enumeration establishes that the resulting conclusions
cover the required lower-bound argument.
